# 아이온 (EYEON) — 졸음운전 방지 시스템

> 웹캠으로 운전자의 얼굴을 실시간 분석하여 눈 감김·고개 숙임 등 졸음 징후를 감지하고, 위험 상황에서 즉시 경고를 제공하는 졸음운전 방지 시스템입니다.

---

## 프로젝트 개요

### 배경 및 필요성
졸음운전은 반응 속도와 판단력을 크게 떨어뜨려 대형 교통사고로 이어지는 주요 원인 중 하나입니다.
운전자가 스스로 졸음을 인지하기 어려운 경우가 많기 때문에, **실시간으로 졸음 상태를 감지하고 경고하는 시스템**의 필요성이 큽니다.

### 프로젝트 목표
저렴한 웹캠만으로 운전자의 얼굴을 실시간 촬영·분석하여, **눈 감김과 고개 숙임 등 졸음 징후를 감지하고 즉시 경고음을 울리는 것**을 목표로 합니다.

### 주요 기능
- 웹캠을 통한 실시간 얼굴 인식
- 눈 감김(눈 뜸/감음) 상태 감지
- 고개 숙임(졸음 자세) 감지
- 졸음 판단 시 경고 알림(경고음/화면 표시)

---

## 사용 기술

| 구분 | 내용 |
|------|------|
| 언어 | Python |
| 영상 처리 | OpenCV |
| AI 추론 | OpenVINO (사전 학습 모델 활용) |

### 사용 모델 (OpenVINO Open Model Zoo)
- `face-detection-adas-0001` — 얼굴 검출
- `open-closed-eye-0001` — 눈 뜸/감음 상태 판별
- `head-pose-estimation-adas-0001` — 머리 각도(고개 숙임) 판별

> 세 가지 모두 사전 학습된 모델이라 별도 학습 없이 사용할 수 있습니다.

---

## 동작 방식

1. 웹캠에서 실시간 영상 프레임 입력
2. 얼굴 검출 → 눈 영역 및 머리 각도 추출
3. `open-closed-eye-0001`로 눈 감김 여부 판별
4. `head-pose-estimation-adas-0001`로 고개 숙임 각도 판별
5. 눈을 일정 프레임 이상 연속으로 감았거나 고개가 기준 각도 이상 숙여지면 → **졸음으로 판단**
6. 졸음 판단 시 → **경고음 및 화면 경고 출력**
